# CafeteriaBot

Telegram-бот для работы кафетерия: просмотр меню, работа с корзиной, оформление заказов, оплата и административное управление заказами[cite: 1].

## Структура проекта

```text
cafeteriabot/
├── admin_handlers/
│   └── handlers.py              # Дополнительные обработчики администратора[cite: 1]
├── data/
│   └── menu_main.py             # Данные основного меню[cite: 1]
├── database/
│   ├── models.py                # Модели таблиц базы данных[cite: 1]
│   └── requests.py              # Запросы и работа с данными в БД[cite: 1]
├── handlers/
│   ├── admin/
│   │   └── order_management.py  # Управление заказами со стороны администратора[cite: 1]
│   └── user/
│       ├── cart.py              # Логика работы с корзиной пользователя[cite: 1]
│       └── menu.py              # Просмотр меню и навигация пользователя[cite: 1]
├── keyboards/                   # Клавиатуры бота[cite: 1]
├── middleware/
│   └── outer_middleware.py      # Внешние middleware (обработка контекста, проверки и т.д.)[cite: 1]
├── payments/
│   └── payment.py               # Логика проведения оплат[cite: 1]
├── states/
│   └── Orderstate.py            # Состояния (FSM) оформления заказа[cite: 1]
├── utils/                       # Вспомогательные утилиты[cite: 1]
├── config.py                    # Загрузка конфигурации и переменных окружения[cite: 1]
├── main.py                      # Точка входа и запуск бота[cite: 1]
└── README.md                    # Документация проекта[cite: 1]
```

> Примечание: локальное виртуальное окружение (`venv/`), кэш Python (`__pycache__/`), файл окружения с секретами (`.env`) и локальная база данных (`monti.db`) не должны попадать в репозиторий — добавьте их в `.gitignore`[cite: 1].

## Основные возможности

* **Пользовательский сценарий:** просмотр меню (`handlers/user/menu.py`, `data/menu_main.py`), управление корзиной (`handlers/user/cart.py`), пошаговые состояния оформления заказа (`states/Orderstate.py`) и оплата (`payments/payment.py`)[cite: 1].
* **Административный сценарий:** обработка и управление заказами (`handlers/admin/order_management.py`, `admin_handlers/handlers.py`)[cite: 1].
* **Промежуточные слои (Middleware):** обработка событий до/вокруг хендлеров (`middleware/outer_middleware.py`)[cite: 1].
* **Работа с данными:** описание моделей и запросов к базе данных (`database/models.py`, `database/requests.py`)[cite: 1].

## Безопасность и подготовка к публикации

* Убедитесь, что `.env` и локальные файлы БД (`*.db`) исключены через `.gitignore`[cite: 1].
* Не коммитьте токены, ключи API и персональные или тестовые данные пользователей.
